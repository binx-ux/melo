# Contributing

You can change Melo. Keep the credits for kyn and Luna in every file you touch. Do not sell the code or a changed copy.

## Changes

Open an issue before a large change. Small fixes can go straight to a pull request.

Keep the section files as they are:

- `src/core.lua` for hub setup
- `src/functions.lua` for feature code
- `src/screens.lua` for the loader and notices
- `src/games.lua` for game kits
- `src/ui.lua` for the menu
- `src/boot.lua` for startup

`init.lua` loads those files in that order as one script. Do not reorder them unless you know the scope still lines up.

## Pull requests

Say what changed and how you ran it. Do not add a co-author trailer.
