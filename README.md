## Run

Execute `init.lua`.

If the `src` folder is next to `init.lua`, it reads those files. If not, it loads them from this repo.

## Files

| File | What it is |
| --- | --- |
| `init.lua` | Loads the sections in order |
| `src/core.lua` | Hub setup and executor check |
| `src/functions.lua` | Aim, ESP, movement, audio, configs |
| `src/screens.lua` | Loader, notice, starter prompt |
| `src/games.lua` | MM2 and Phantom Forces |
| `src/ui.lua` | Menu and command bar |
| `src/boot.lua` | Startup |

Press RightControl for the menu. Press `'` for commands.
